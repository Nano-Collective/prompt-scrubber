# n8n-nodes-prompt-scrub

An n8n community node for running `@nanocollective/prompt-scrub` inside local
workflow steps.

Install it from the n8n community nodes interface or with:

```bash
npm install n8n-nodes-prompt-scrub
```

The node supports Inspect, Scrub, Scrub selected fields, and Rehydrate. See the
repository's [n8n integration guide](https://github.com/Nano-Collective/prompt-scrubber/blob/main/docs/integrations/n8n.md)
for the recommended setup and the warning about inline session maps.
